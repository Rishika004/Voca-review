# Deploying Aria v2

Three pieces: **backend (token server + agent worker) → Render**, **frontend → Vercel**.
LiveKit itself is already cloud-hosted (LiveKit Cloud), nothing to deploy there.

## 1. Push code to GitHub

The repo must be on GitHub for both Render and Vercel.
**IMPORTANT: never commit `.env`, `token.json`, or `credentials.json`** — add them to `.gitignore`.

## 2. Backend → Render (free)

1. Go to https://render.com → sign up (GitHub login)
2. **New → Web Service** → connect your repo
3. Settings:
   - Root Directory: `hackon_tts/v2-livekit/backend`
   - Runtime: Python 3
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `bash start.sh`   (runs agent worker + token server together)
   - Instance type: **Free**
4. **Environment variables** (Environment tab) — copy every key/value from your local `.env`:
   `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET`, `DEEPGRAM_API_KEY`,
   `GROQ_API_KEY`, `GROQ_MODEL`, `ELEVEN_LABS_API_KEY`, `ELEVEN_LABS_VOICE_ID`,
   `TTS_PROVIDER`, `GMAIL_USER`, `GMAIL_APP_PASSWORD`, `NOTIFY_EMAIL`, `MEET_LINK`
   plus: `GOOGLE_TOKEN_FILE=/etc/secrets/token.json`
5. **Secret Files** (same tab): add a secret file named `token.json`, paste the
   contents of your local `token.json` (generated by `google_auth_setup.py`)
6. Deploy. Copy the service URL, e.g. `https://aria-v2.onrender.com`

> Free-tier note: Render free services sleep after 15 min of inactivity and take
> ~40s to wake. For a scheduled demo, open the URL a minute beforehand, or set up
> a free pinger (https://cron-job.org) hitting `https://<your-app>.onrender.com/api/calls/history`
> every 10 minutes.

## 3. Frontend → Vercel (free)

1. Go to https://vercel.com → sign up (GitHub login)
2. **Add New → Project** → import the repo
3. Root Directory: `hackon_tts/frontend`  (framework auto-detected: Next.js)
4. Environment variable:
   - `NEXT_PUBLIC_V2_API_URL` = `https://<your-render-app>.onrender.com`
5. Deploy. Your app is at `https://<project>.vercel.app/v2`

## 4. Verify

1. Open `https://<render-app>.onrender.com/api/calls/history` → should return `{"calls":[]}`
2. Open `https://<project>.vercel.app/v2` → Start Call → Aria should greet you

## Costs / limits recap

| Service | Free tier | Watch out |
|---|---|---|
| LiveKit Cloud | 50 GB/mo | plenty |
| Render | 750 hrs/mo | sleeps when idle |
| Vercel | 100 GB/mo | plenty |
| Groq | 100K tokens/day, 12K/min (70B) | ~35 turns/day |
| ElevenLabs | 10K credits/mo (~10 min) | falls back: remove TTS_PROVIDER for Deepgram voice |
| Deepgram | $200 one-time credit | STT + fallback TTS |
